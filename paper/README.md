# Manuscript

IEEE journal-format (`IEEEtran`, `journal` option) write-up of the AIPA-CRS work.

- `body.tex` — the manuscript text (title, abstract, sections). Edit prose here.
- `preamble.tex` — shared packages and macros.
- `main.tex` — two-column IEEE journal wrapper around `body.tex`.
- `main_onecol.tex` — single-column 12pt wrapper around the same `body.tex` (draft / Word-style layout).
- `build_docx.sh`, `docx_shim.tex`, `ieee.csl` — pandoc export of `body.tex` to `main_onecol.docx` (Word, single column, IEEE-style references).
- Generated figures are read from `../outputs/figures/`.
- `figures/fig00_architecture.png` — hand-drawn architecture figure (Fig. 1). It is maintained by hand and is
  not overwritten by the pipeline, which writes its own auto-drawn version to `outputs/figures/`.
- `refs.bib` — bibliography.
- `tables/*.tex` — generated by `python scripts/build_paper_tables.py` from `outputs/results/*.csv`
  (includes `macros.tex` with the run configuration and dataset counts used in the text).
- `main.pdf`, `main_onecol.pdf`, `main_onecol.docx` — compiled outputs.

Rebuild after re-running the pipeline or notebook:

```bash
python scripts/build_paper_tables.py
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
pdflatex main_onecol && bibtex main_onecol && pdflatex main_onecol && pdflatex main_onecol
./build_docx.sh   # needs pandoc >= 2.11 and pdftoppm (poppler-utils); or `pip install pypandoc_binary`
```

Requires a TeX Live installation with `IEEEtran` (`texlive-publishers` on Debian/Ubuntu; included in MacTeX).
The prose quotes numbers from the full run (`--run-mode full`); if the run changes, re-read the Results section against the regenerated tables.
